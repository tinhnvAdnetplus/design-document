# Execution Steps: 02-event-protocol

## Prerequisites
- `jq` installed for JSON processing and schema validation.
- `sha256sum` for integrity validation.
- Bash shell.

## Execution Steps
1. Navigate to the scripts directory:
   ```bash
   cd scripts/
   ```
2. Run the master script:
   ```bash
   ./run_all.sh
   ```

## Expected Output
- Validation failures for files in `invalid_events/`.
- Successful appends for files in `valid_events/`.
- Rejection of duplicate append attempt during idempotency test.
- Correct log sequence generated by projection rebuild.
